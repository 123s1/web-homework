# 博物馆预约系统功能测试流程

## 1. 文档目的

本文档用于指导博物馆预约系统的功能测试执行，确保测试过程覆盖项目要求中的主要业务功能，并为后续编写《功能测试报告》提供测试用例、测试步骤、预期结果、实际结果和测试截图依据。

## 2. 编写依据

本测试流程依据以下内容编写：

- `项目要求分析.md` 中关于功能测试报告的要求。
- `project-docs/系统设计文档初稿.md` 中的系统功能模块和业务流程。
- `project-docs/数据库设计.md` 中的核心数据表设计。
- `project-docs/后端接口设计.md` 中的接口定义。
- `project-docs/前端开发设计.md` 中的前端页面和开发顺序。
- 已完成的本地联调结果和当前项目实现情况。

## 3. 测试范围

本次功能测试覆盖以下模块：

1. 游客端功能。
2. 管理员端功能。
3. 表单校验与异常提示。
4. 预约记录查询与 CSV 导出。
5. 系统状态查看。
6. 前后端基本联通性验证。

本次功能测试不覆盖以下内容：

- 大规模并发性能测试。
- 生产环境部署测试。
- 第三方登录、短信验证码、扫码核验等未纳入当前主线的扩展功能。

## 5. 测试前置条件

测试前需要确认：

1. MySQL 服务已启动。
2. 已创建并初始化数据库 `museum_reservation`。
3. 已导入 `database/schema.sql`。
4. 后端已启动。
5. 前端已启动。
6. 浏览器能正常访问前端页面。
7. 后端健康检查接口正常。

### 5.1 启动后端

进入后端目录：

```powershell
cd E:\web-homework\museum-reservation-system\backend
```

推荐使用一次性绕过脚本策略的方式启动：

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\start-backend-interactive.ps1
```

输入 MySQL 密码后，看到以下内容表示启动成功：

```text
Started MuseumReservationApplication
```

### 5.2 启动前端

进入前端目录：

```powershell
cd E:\web-homework\museum-reservation-system\frontend
```

启动前端：

```powershell
npm.cmd run dev
```

浏览器访问控制台输出的地址，例如：

```text
http://127.0.0.1:5173
```

### 5.3 健康检查

浏览器访问：

```text
http://127.0.0.1:8080/api/health
```

预期返回：

```json
{
  "success": true,
  "data": {
    "status": "UP",
    "database": "UP"
  }
}
```
